# Agrawal Agencies - Steel & Plumbing Wholesale Distributor

Premier building materials wholesaler supplying top-grade reinforcement steel (Tata Tiscon, JSW Neosteel, SAIL, Kalika, Uma, SRJ), structural steel sections, and Prince Piping solutions with a 3.5-acre warehouse and on-site 80 MT weighbridge.

## Features

- **Multi-Page Architecture**: Dedicated sections for Products, Partner Brands, Engineering Calculator, Logistics Infrastructure, About Us, and Commercial Contact.
- **Dedicated Brand Showcases**: In-depth profiles and product lines for Primary and Secondary steel producers, Prince Piping, and Bharat Precast.
- **Steel Weight & Tonnage Estimator**: Interactive calculator for Rebar ($d^2/162$), MS Flat, Round Bar, and Square Bar.
- **Quote / RFQ Cart System**: Instant quotation requests with direct WhatsApp and sales engineering dispatch hotlines.
- **Responsive Layout**: Tailored for laptop, desktop, and mobile viewports.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
